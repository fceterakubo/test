# ぴょんぴょん なわとび

「譜面を見ずに、音を聞いてノる」タイプのリズムゲームの試作です。
ミニゲーム1本目は「なわとび」です。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし）。

- なわが地面に当たる瞬間にジャンプ（画面タップ / スペースキー）
- 「ゆっくり〜」の合図：なわが1回だけ2拍かけて回る
- 「タタッ！」の合図：8分音符で2回すばやく跳ぶ
- 判定：ジャスト ±45ms / OK ±90ms / ぎりぎり ±150ms、それより外はミス
- 判定が合わないときは、タイトル画面の「タイミング補正」で調整

## 音と見た目の役割

- **ベース（土台）**：ドラムとベースが4分音符で一定の拍を刻む。メロディは持たない
- **リード（遊ぶ音）**：ジャンプのタイミングでだけ鳴る。変則リズムがそのまま旋律として聞こえるので、リードに合わせて跳ぶ
- **目で計る**：なわの影が地面に近づくほど濃く小さくなり、地面に当たる瞬間に土ぼこりが立つ

## 仕組み

- 音はすべて Web Audio API で合成し、曲・合図を開始時にまとめて予約再生
- 判定と描画はどちらも `AudioContext.currentTime` を基準にしており、音と絵がずれない
- 譜面は `CHART`（ジャンプ間隔の拍数の並び）で定義。`BAR` と `SONG` を書き換えれば曲構成を変えられる
