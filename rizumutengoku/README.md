# リズムあそび

「譜面を見ずに、音を聞いてノる」タイプのリズムゲーム集の試作です。
`index.html` をブラウザで開くだけで遊べます（ビルド不要・外部ライブラリなし・1ファイル）。

## 共通の考え方

- **ベース（土台）**：ドラムとベースが4分音符で一定の拍を刻む。メロディは持たない
- **リード（遊ぶ音）**：遊ぶタイミングでだけ鳴る音。お手本として鳴るか、プレイヤーの入力で鳴る
- **目でも計れる**：なわの影・おばけの顔出し・部品の移動など、タイミングが絵でもわかる
- 判定：ジャスト ±45ms / OK ±90ms / ぎりぎり ±150ms、それより外はミス

## ミニゲーム

| # | ゲーム | 鍛えるリズム感 | 操作 |
|---|---|---|---|
| 1 | ぴょんぴょん なわとび | 間隔の変化（ゆっくり／タタッ） | 1ボタン |
| 2 | まねっこ小鳥 | お手本の記憶と高低の聞き分け | 2ボタン |
| 3 | ぺったん もちつき | ウラ拍 | 1ボタン |
| 4 | ネジしめ工場 | 「何拍後」を数える・さわらない判断 | 1ボタン |
| 5 | おばけやしき | 左右の音の聞き分け（イヤホン推奨） | 2ボタン |
| 6 | ふうせんリレー | 長さ（押す＋離す） | 長押し |
| 7 | だまって手拍子 | 無音でのテンポ維持 | 1ボタン |

操作：1ボタンはタップ / スペース。2ボタンは F・J（または画面の左右タップ）。プレイ中は Esc でやめる。

## 仕組み

- 音はすべて Web Audio API で合成し、曲・お手本・合図は開始時にまとめて予約再生
- 判定と描画はどちらも `AudioContext.currentTime` を基準にしており、音と絵がずれない
- ミニゲームは `build / schedule / onJudge / onWhiff / onMiss / draw`（長押しは `onRelease`）を持つオブジェクトで、`GAMES` に足せば選択画面に並ぶ
- ヒットの種類：通常 / `type: "up"`（離す判定）/ `avoid: true`（さわってはいけない）/ `key: "L" | "R"`（2ボタン）
